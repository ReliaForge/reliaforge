# Repositories

ReliaForge is organized across four repositories. Use this table to find the owning code or guide.

| Repository | What you will find |
| --- | --- |
| [`reliaforge`](https://github.com/SajoLuo/reliaforge) | Project website, getting-started guides, cross-repository architecture, security overview, and roadmap |
| [`reliaforge-backend`](https://github.com/SajoLuo/reliaforge-backend) | Python runtime, management API, WebSocket/SSE proxy auth, bundled example plugins, plugin scaffold, and backend docs |
| [`reliaforge-frontend`](https://github.com/SajoLuo/reliaforge-frontend) | React console, runtime ESM plugin host, `@reliaforge/plugin-sdk`, UI tests, and the read-only online demo |
| [`reliaforge-plugins`](https://github.com/SajoLuo/reliaforge-plugins) | Official full-stack infrastructure plugins (`infra_overview`, `proxmox`, `kubernetes`, `gitops_argocd`, `observability`, `ops_audit`) and single-container image build |

For detailed runtime or SDK behavior, read the documentation inside the repository that owns that
code. Each repository versions and publishes releases independently.
